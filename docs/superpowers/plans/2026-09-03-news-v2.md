# Forex Factory News V2 Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the flattened News proof of concept with a durable collector, normalized SQLite model, media cache, translations, and V2 API that preserve every Forex Factory News section and ordered detail segment.

**Architecture:** A browser source returns rendered HTML; pure adapters turn it into immutable observation batches; a News-specific repository applies those observations transactionally and maintains persistent detail/media/translation work. FastAPI exposes normalized V2 reads while V1 serializers remain compatible until the iPhone client migrates.

**Tech Stack:** Python 3.12, FastAPI, aiosqlite/SQLite WAL, Playwright CDP, selectolax, httpx, Pydantic Settings, pytest, Ruff, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-09-03-news-v2-design.md`

## Global Constraints

- Keep the existing calendar collection and API behavior unchanged.
- Use Forex Factory numeric news IDs as canonical article identities.
- Treat category membership as durable; treat Latest and Hot as dynamic placements.
- Normalize source times to aware UTC while preserving source text and configured timezone.
- Commit English source data before detail, media, or translation work.
- Do not crawl external publisher full-story pages.
- Do not expose UI SVGs, avatars, emoji, or source logos as content media.
- Preserve `/api/v1/news` until a verified V2 iPhone build replaces it.
- Use only existing runtime dependencies unless a later plan amendment explains a new dependency.
- Every schema and job operation must be idempotent and restart-safe.

- `app/migrations.py`: versioned SQLite migrations.

- `app/collector/browser.py`: live listing, detail, and More-continuation navigation only.
- `app/config.py`: source timezone, paths, limits, and worker cadence.

- `compose.yaml`: persistent media/snapshot paths and runtime settings.
- `tests/news/`: News V2 parser, repository, service, API, media, and backfill tests.
- `tests/fixtures/news_v2/`: representative rendered HTML fixtures.
